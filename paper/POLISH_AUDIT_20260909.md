## 图表是否还需要增加

已增加“Selection outcomes within the frozen top ten”表 IV。原总表报告最终准确率，但不直接展示检索与选择各自损失。新表将每种选择策略分解为 103 个可召回目标中的成功和失败，并固定注明另有 97/200 个目标未召回。五个完整 Agent 的计数和条件成功率逐行核对 `results/agent-multimodel-20260909/summary.json`；检索和无 KB DeepSeek 分别沿用正文的 41、44 次正确预测。

当前正文为两张方法图、六张表，不建议继续增加另一张架构图或把总表重复画成柱状图。若后续有额外版面，最有价值的是实际谱图的成功／失败案例，展示实验谱与正确、错误候选理论谱在相同覆盖区间内的差异。但这需要真实逐查询谱线与评分记录，本轮没有读取被限制的大型数据目录，也没有用示意谱代替实验案例。

数据划分已经在 IV-A 交代清楚，可在补充材料整理为 train/dev/test × 谱数/分子组数/参考池大小的紧凑表。训练集为 601 谱/565 组，开发集为 149 谱/142 组，测试集为 200 谱/200 组；开发和测试索引分别包含 10,704 与 10,000 个身份。避免把 10,967 条理论记录误写为唯一分子数。该表提升查阅便利，但不会增加科学证据，故本轮没有继续占用正文。

## 已补足的结论

检索与选择是两个独立瓶颈。Claude 是当前恢复策略下准确率最高的已测选择器，但仅选中 58/103 个可召回目标，仍遗漏 45 个；检索外还有 97 个目标。结论现在明确指出，提高召回率并不自动保证可靠的最终识别。

规则兼容性不足以解决完整结构歧义。非 LLM 规则重排会损失正确预测，DeepSeek 的知识干预没有稳定额外收益。该结果已在结论中形成有边界的综合判断，没有外推成“知识对所有 LLM 无用”。

五种子测试均值提高不等于已确立稳定测试收益。删除原讨论末段“demonstrated closed-library retrieval improvement”的过强概括，统一为开发集收益明确、测试收益仍有不确定性。保留配对测试增益区间 [-0.58, 15.18] pp，以及反映预算修复和固定测试集反复观察的限制。

独立仪器数据、未见分子、竞争方法同等适配、统一预算重复 LLM 评估与测试集同规则四臂消融仍缺证据。这些属于后续验证，不能通过润色补成已完成结论。现有“Expert-Like”题目也没有人类专家对照支持；因 camera-ready 可能要求题目固定，本轮保留原题，建议作者核对其是否作为系统命名而非已验证能力主张。

## 术语与正文分配

| 固定术语 | 定义与本轮处理 |
|---|---|
| Exact@10 | 前十候选是否含完整精确身份；不等于最终识别率 |
| full Agent | 冻结 seed-0 encoder + legacy KB + 指定 LLM |
| candidate-only DeepSeek | 不含 KB；不能与完整 Agent 混为同一条件 |
| conditional selection success | 正确识别数 / 103；不同于全测试集分母 200 |

| effective validity | 输出恢复后的可评分率，不等于初始格式合规率 |

| 证据类别 | 位置与处理 |
|---|---|
| core discovery：配对域适配与检索 | 原表 I–II 及正文保留；摘要统一小数精度 |
| heterogeneity：模型依赖 | 原总表 III 保留；新增表 IV 展示条件选择率 |
