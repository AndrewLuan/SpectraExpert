# 多模型 Agent 评测：预算修复与最终答案格式归一化

同一 exact-v2 Test-200、冻结 encoder Top10 与 legacy KB。结构指标沿用原评分器；Gemini 先进行无歧义最终答案归一化，所有模型的分母均为 200。

| 模型 | Valid | Exact | Tanimoto（有效样本） | Chemical GED（可计算 n） | Legacy GED | nGED |
|---|---:|---:|---:|---:|---:|---:|
| gpt5 | 200/200 | 37/200 (18.5%) | 0.3082 (200) | 5.4603 (189) | 8.8950 | 0.1876 |
| o3 | 200/200 | 41/200 (20.5%) | 0.3352 (200) | 5.0890 (191) | 8.3050 | 0.1779 |
| claude | 199/200 | 58/200 (29.0%) | 0.4207 (199) | 4.4404 (193) | 7.0653 | 0.1563 |
| gemini | 200/200 | 33/200 (16.5%) | 0.2985 (200) | 5.4688 (192) | 8.5700 | 0.1889 |
| deepseek | 200/200 | 44/200 (22.0%) | 0.3575 (200) | 5.0785 (191) | 8.2050 | 0.1748 |

o3 原 78 条空正文的 completion budget 均被 reasoning tokens 用完。仅按空正文截断条件提高预算补跑，122 条原有正文原样复用。最终表为此恢复策略结果，不能称所有 200 条均使用同一较大预算。

o3 首次补跑上限为 16,384 tokens；仍有一条再次耗尽预算，进一步以 32,768 tokens 补跑。全部尝试和不同预算均保留。

GPT-5 保留 50 条成功结果，150 条空正文以 32,768-token 上限补跑；全部均恢复。Gemini 原始严格字段合规为 3/200，经候选索引或唯一候选 SMILES 的确定性格式归一化后为 200/200；未新增 API 请求，未改变原始候选选择。解析器只使用回答和候选，不接触真值；原始表与恢复后表须区分。有效样本上的 Tanimoto/GED 分母不同，不能直接作为跨模型能力排名。共同可计算子集的配对差异、95% 区间及 invalid=0 的全样本 Tanimoto 见 summary.json。

JSON 同时包含检索新增/丢失命中、Top10 内条件选择率、group match、指标均值/中位数/标准差、nGED、调用 tokens、延迟中位数/P95 和来源哈希。o3 用量包含首轮及补跑；货币费用因无核实账单保留为空。DeepSeek 用量未采集，不填零。

这些结果来自已多次观察的固定测试集；置信区间仅为探索性查询配对重采样，不反映模型 API 多次独立采样的不确定性。

相同归一化规则已检查其他模型的原始回答，未改变其已有合法选择。GPT-5 和 o3 的恢复属于不同预算的失败恢复策略，不等同于全样本统一较大预算的独立重跑。

报告区分 initial_schema_compliant_count（初始格式合规）与 valid（恢复后可评分输出）；Gemini 的恢复不表示模型已学会指定格式。
