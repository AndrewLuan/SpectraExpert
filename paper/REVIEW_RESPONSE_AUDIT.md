## 当前不能声称已经完成的实验

1. MolSpectLLM 的同协议 Raman 测试，以及所有竞争模型的同资源实验域适配。
2. 同一套 15-mode 规则的完整 Test-200 四臂实验。
3. 与当前配对编码器使用同样数据、容量及训练预算的非对比损失消融。
4. LLM 多次采样、跨提供商的稳定性与历史格式失败原因的系统检查。
5. 新 MODIFY 门控或化学验证策略的实际收益。
6. 独立仪器、未见分子、重新封存测试集上的泛化。
7. 货币费用、全部方法的端到端延迟与一致硬件下的全面成本比较。

这些缺口不通过本轮论文编辑自动补成已完成实验，也未启动训练或新的 API 调用。正文采用最新已有结果，报告不利结果与不确定性。
