# Raman Exact Match@10 多随机种子复核

单次训练中，随机代理与困难负样本组合（hard）在固定 200 条测试谱上取得 51.5% 的
Exact Match@10，而同一轮的新划分 baseline 为 52.5%。单个种子的测试顺序与验证顺序
并不一致，因此本轮用 5 个配对随机种子复核 hard 相对 baseline 的稳定性。两组共享数据、
网络、训练步数、采样规模和每个种子的初始权重，差别仅为理论域视图与困难负样本机制。

## 复核协议

使用 seed 0、1、2、3、4。seed=0 复用已经冻结的 run01 checkpoint，补算 baseline 的
测试排名；seed=1–4 全部从头训练。每个新增种子在同一张 GPU 上依次运行 baseline 和
hard，避免一对实验分布到负载不同的设备。每个种子内部的两组初始权重内容哈希一致，
不同种子使用不同初始化与采样序列。

数据划分、10,704 个验证候选、10,000 个最终测试候选、模型结构、每轮 160 步、最多
40 轮及早停规则均沿用 `raman_top10_surrogate_run01/protocol.json`。checkpoint 只按独立
验证集的组等权 Exact@10、组等权 Exact@1 和训练损失选择。测试谱在 checkpoint 冻结后
读取，不参与早停或种子选择。完整 canonical SMILES 保留立体化学和同位素。

报告中的“±”是 5 个种子的样本标准差。均值 95% 区间使用以种子为独立重复单位的
Student t 区间，而不是将 200 条相关查询当作独立训练重复。5 个种子仍然较少，区间只能
用于量化本轮训练随机性。

也显示 hard 的种子波动小于 baseline。

## 固定 200 条测试结果

| seed | baseline Exact@10 | hard Exact@10 | hard − baseline |
|---:|---:|---:|---:|
| 0 | 52.5%（105/200） | 51.5%（103/200） | −1.0 pp |
| 1 | 41.0%（82/200） | 53.5%（107/200） | +12.5 pp |
| 2 | 47.0%（94/200） | **57.5%（115/200）** | +10.5 pp |
| 3 | 41.0%（82/200） | 53.5%（107/200） | +12.5 pp |
| 4 | 50.0%（100/200） | 52.0%（104/200） | +2.0 pp |
| 均值 ± SD | 46.3% ± 5.22% | **53.6% ± 2.36%** | +7.3 ± 6.35 pp |

hard 在测试集 4/5 个种子上优于同种子 baseline，seed=0 低 1 个百分点。配对种子差值
的均值 95% t 区间为 [−0.58, +15.18] 个百分点，仍跨零。因此，测试结果与验证方向总体
一致，但尚不足以把 hard 相对新 baseline 的增益称为统计上稳定。

hard 的测试绝对表现较稳定，范围为 51.5%–57.5%。5 种子平均的 Exact@1、@5、@10
分别为 19.5% ± 1.70%、43.9% ± 1.98%、53.6% ± 2.36%；baseline 对应为
15.5% ± 4.18%、35.6% ± 4.13%、46.3% ± 5.22%。历史模型 C 的单次结果是
14.0%、36.5%、45.0%。所有 hard 种子都超过历史 C 的 45% Top10，但历史 C 使用不同的
训练/验证协议且只有一个种子，这一对比是历史参照，不是配对机制检验。

## 域偏移来源分层

| 测试理论来源 | baseline Exact@10，5-seed | hard Exact@10，5-seed | 配对差值 |
|---|---:|---:|---:|
| QME14S，138 条 | 51.88% ± 5.99% | **59.86% ± 1.67%** | +7.97 ± 5.77 pp |
| fg26，62 条 | 33.87% ± 5.10% | **39.68% ± 6.71%** | +5.81 ± 10.43 pp |

QME14S 的配对差值均值区间为 [+0.80, +15.14] 个百分点；fg26 为
[−7.14, +18.75] 个百分点。hard 相对本轮 baseline 的增益不只来自 fg26，但 fg26 的
不确定性更大，仍是主要薄弱来源。

与历史模型 C 比较时，解释不同：历史 C 的 QME14S Top10 为 59.42%，已经接近 hard 的
5-seed 均值 59.86%；fg26 则从历史 C 的 12.90% 上升到 hard 均值 39.68%。因此，新训练
协议相对旧模型的净改善主要来自 fg26，而 hard 相对新 baseline 的机制增益分布在两个来源。

## 结论与使用建议

多种子结果确认了两点。第一，新训练协议不再依赖 seed=0 的偶然结果：hard 在 5 个种子
上的 Top10 都达到至少 51.5%，平均 53.6%，明显高于历史 C 的单次 45%。第二，hard 相对
同协议 baseline 在独立验证上有一致优势，但固定测试的 5-seed 配对区间仍跨零。论文中
可以报告验证层面的稳定机制增益和测试层面的平均改善，不能声称困难负样本已经在最终
测试上取得显著优势。

如果部署只选一个现有 checkpoint，应按预先定义的验证指标选择，而不能按测试 57.5%
挑 seed=2。5 个 hard checkpoint 中，验证指标最高的是 seed=2，因此它恰好也是合法选择，
但这一事实应由验证记录证明，并保持测试结果不参与选择逻辑。更稳健的下一步是根据验证集
预先确定多模型分数融合，再一次性报告融合结果；不能在测试集上尝试多种融合权重。
