# 用真实配对与曲线代理提高 Raman Exact Match@10

本轮检验来源相关的理论→实验曲线校正是否能提高完整结构的前十召回。旧模型 C 的固定
200 条实验测试 Exact Match@10 为 90/200（45%），原始谱余弦 kNN 为 22/200（11%）。
这两个数字是历史基准，不作为本轮 checkpoint 或训练方案的选择条件。

**四组已完成，按独立验证选出的 hard 模型在固定测试上的 Exact Match@10 为
103/200（51.5%），比旧 C 增加 13 条。净增益集中在 fg26，但单种子配对区间仍跨零，
不能据此宣称已经稳定优于旧模型或充分解决域偏移。**

后续 5 个配对随机种子复核显示：hard 验证组等权 Exact@10 为 54.86% ± 2.26%，
测试 Exact@10 为 53.6% ± 2.36%。完整结果和解释见
[多随机种子复核](raman-top10-multiseed-2026-09-09.md)。本报告以下内容保留单种子结果。

## 重训与最终结果

四组均完成 40 轮，耗时约 501–532 秒，训练与最终评测退出码全部为 0。初始权重内容
哈希四组一致：`71a9c6ed169e4bc23df29bbdce6a00eb42e9fa9c7d4b1da1739a7fb748f9b160`。

| 组别 | 最佳轮次 | 验证逐谱 Exact@10 | 验证组等权 Exact@10 |
|---|---:|---:|---:|
| baseline | 33 | 73/149（48.99%） | 51.06% |
| fixed | 35 | 77/149（51.68%） | 52.82% |
| random | 32 | 77/149（51.68%） | 52.82% |
| hard | 36 | 80/149（53.69%） | **54.58%** |

hard 比新划分 baseline 的验证组等权 @10 高 3.52 个百分点，配对组 bootstrap 区间为
[-5.28, 12.32] 个百分点；fixed 与 random 都高 1.76 个百分点，区间也跨零。它们是各组
已选 checkpoint 上的探索性区间，没有校正选型过程，不能把小幅差值视为机制的稳定优势。

只对按预设验证规则选出的 hard 运行本轮最终 200 条评测：

| 方法 | Exact@1 | Exact@5 | Exact@10 |
|---|---:|---:|---:|
| 原始谱 kNN | 1/200（0.5%） | 11/200（5.5%） | 22/200（11%） |
| 历史模型 C | 28/200（14%） | 73/200（36.5%） | 90/200（45%） |
| 新 hard 模型 | **41/200（20.5%）** | **87/200（43.5%）** | **103/200（51.5%）** |

相对旧 C，35 条查询新增进入 Top10，22 条掉出，净增加 13 条。@10 差值 +6.5 个百分点，
配对 bootstrap 95% 区间为 [-0.5, 13.5] 个百分点。相对 kNN 的差值为 +40.5 个百分点，
区间 [33.5, 47.5] 个百分点。kNN 的 @1/@5/@10 全部复现此前固定候选库结果。

| 理论来源 | 历史 C 的 Top10 | 新模型的 Top10 |
|---|---:|---:|
| QME14S | 82/138（59.42%） | 82/138（59.42%） |
| fg26 | 8/62（12.90%） | 21/62（33.87%） |

来源分层是事后诊断：本轮净命中数提升来自 fg26，QME14S 总命中数持平，并不表示
QME14S 逐样本排名完全不变。液相从 72/147 提高到 84/147，固相从 17/51 到 18/51，
相态不详维持 1/2。数据来源与相态存在混杂，不能将这些差异直接归因为某个物理机制。

当前仍有 97/200 条正确结构不在前十，远未达到近 100%。多种子复核已经完成；下一轮
应评估训练预算和多理论参考的结构级聚合。
本轮最终索引每结构只有一条参考，多参考训练与多参考检索是不同机制，后者尚未实施。

## 统一划分与评价口径

新 surrogate 数据沿用 `raman_surrogate_exact_pairs_v1/split.json`，实验训练包含
565 个分子组、601 条谱，验证包含 142 个组、149 条谱。200 个固定测试组被完全排除于
实验训练、代理参数拟合及模型选择。完整 canonical SMILES 保留立体化学和同位素。

新验证集的 142 个组中有 101 个曾用于旧模型 C 的实验训练；旧验证集的 177 个组中有
136 个进入新 surrogate 训练。因此四组从相同随机初始化重新训练，不从 C 续训；旧模型
与新模型只能在固定测试基准上作历史比较，不能用新验证集公平评价旧模型 C。

验证使用固定 10,704 个唯一结构，包括原始 10,000 个结构及 704 个补充结构。共有
10,967 条理论参考，允许同一完整结构的多条理论记录作为正样本。每个结构在验证索引中
仍只有一条固定参考，避免重复谱占用 Top10 槽位。最终测试索引只含原始 10,000 个结构。
原候选的 9,500/500 理论划分保持不变；额外非测试组理论记录可参与训练，验证身份的
理论谱也可参与。这是已知候选理论谱、未见实验查询的闭库设定，不是未见分子泛化。

主选型指标为验证集按分子组等权的 Exact Match@10；并列时依次比较组等权 @1、较低
训练损失。普通逐谱 @1/@5/@10 也完整保存。重复测量先在组内平均，避免测量条数改变
某个分子组的选型权重。最终 200 条只在四组完成、选择写入磁盘后评估唯一所选模型。

## 四组受控训练

| 组别 | 理论查询视图 | 额外参考选择 |
|---|---|---|
| baseline | 在新训练划分上重新拟合的旧经验域增强 | 随机 |
| fixed | 现有来源相关固定代理 | 随机 |
| random | 固定代理附近的受约束随机视图 | 随机 |
| hard | 与 random 相同 | 当前模型的困难负样本 |

四组均使用原 MaskedSpectrumEncoder：长度 3501、patch 16、stride 8、隐藏维度 128、
3 层、4 个注意力头、输出 64 维。随机种子 0，AdamW 学习率 3e-4、weight decay 1e-4，
温度 0.1，梯度裁剪 1。每步 32 条理论合成查询与 32 条真实实验查询，64 条正参考及
32 条额外参考。每轮 160 步、最多 40 轮，连续 8 轮没有改进则停止。

真实配对按来源、结构、测量分层采样，正参考可动态选择同结构同来源的理论记录；四组
共同使用相同的多参考与采样设置。因此 baseline 是公平的新划分对照，不是旧 C 的逐项
复现。四组保留共同的 `create_positive_pair` 基础增强，包括既有小幅噪声与污染峰项；
本轮替换的是其后的域增强部分，不能把 fixed 称为纯物理前向模型。

固定代理只有每来源 3 个参数，使用既有 `raman_curve_proxy_fit_20260909_v1/model.json`。
已校验其拟合绑定同一 surrogate 划分，且没有访问 protected 实验谱。该拟合预算耗尽、
展宽触及 12 cm⁻¹ 上界，因此本轮把它作为已冻结假设，而非充分收敛的物理参数估计。

random/hard 中 20% 视图不施加额外代理变换，20% 使用固定代理，其余 60% 在来源固定
仿射参数附近施加训练配对联合残差的一半，缩放和平移裁剪至原固定搜索范围；展宽在
0 与固定代理宽度之间采样。联合残差仅来自该来源的真实训练配对，未移植其他分子的
完整残差曲线。共同基础增强仍然存在，因此这里的“无额外变换”不是完全未增强谱。

困难负样本从训练实验查询对训练理论参考的当前嵌入排名中挖掘，排除完整结构相同的
参考，每条查询在最近 16 条错误参考中采样。第一轮使用随机额外参考；后续每轮更新。
三组对照同样添加 32 条随机参考，以控制前向计算量。矩形对比损失将同身份参考全部视为
正样本；只对有对应查询的参考计算反向项，不人为制造无正样本的反向目标。

## 固定代理的直接检索检查

无需 encoder，在同一验证候选库对原始理论曲线与固定代理曲线进行余弦检索。每个
查询—候选配对使用实验覆盖、原理论覆盖及代理有效覆盖的共同区域，两种方法的支持域
一致，不对验证实验谱单独拟合。此诊断的掩码口径与历史零填充 raw kNN 不同。

| 方法 | Exact@1 | Exact@5 | Exact@10 |
|---|---:|---:|---:|
| 原始曲线 | 3/149（2.01%） | 3/149（2.01%） | 8/149（5.37%） |
| 固定代理曲线 | 16/149（10.74%） | 32/149（21.48%） | 39/149（26.17%） |

固定代理使 33 条查询新增进入前十，2 条原命中查询掉出前十。按分子组等权的 @10 差值
为 +21.13 个百分点，组重采样 95% 区间为 [14.08, 28.87] 个百分点。这支持曲线校正对
独立结构检索的帮助，尚不能据此推断 encoder 重训一定获益。

## 可复现产物

本地入口为 `scripts/raman_top10_experiment.py`，独立诊断为
`scripts/diagnose_raman_top10.py`。数值检查位于
`tests/scripts/test_raman_top10_experiment.py`：覆盖稳定同分排序、组等权统计、多正样本
及额外参考梯度，2 项通过。

服务器产物根目录：
`/home/user/IRfingerprints/SpectrExpert/outputs/raman_top10_surrogate_run01`。
其中 `protocol.json` 绑定数据、代码、代理哈希与选择规则；每组保存 config、逐轮指标、
best checkpoint、验证排名和 summary。`final/selection.json` 在测试读取前持久化，
`final/per_query.json` 保存最终真实结构名次及前十候选。全部历史数据和 checkpoint 保留。

后处理入口 `scripts/summarize_raman_top10.py` 保存 `comparison.json`，包含四组验证
配对比较、历史 C 的同查询比较及来源/相态分层。所选模型为 `hard/best.pt`，SHA-256：
`023da9724091f58a9ee897ddc07000848f6974093093cfa3cefbbe8f3149b8c5`。

四组通过独立 GPU 进程运行，由脱离 SSH 的父进程收集退出码并在全部成功后执行最终
评测。日志、PID、各组退出码和 pipeline 退出码均保存在上述目录；没有新增定时任务。

本轮是单种子对照。GPU 数值计算未强制逐位确定性，相同初始权重不意味着运行轨迹逐位
相同。若某机制优于对照，还需多种子验证其稳定性。固定 200 条测试已被多次观察，后续
结论应披露这种基准使用历史；受保护的含义是禁止用于梯度或选型，并不意味着从未观察。
