# 同一分子的理论—实验 Raman 域偏移实验

后续以 Top10 为目标的统一划分重训已完成，固定测试 Exact@10 从本报告模型的 45%
提高到 51.5%；详见 [代理增强与困难负样本实验](raman-top10-surrogate-2026-09-09.md)。
以下保留本轮原始结果与设定，两轮验证划分不同。

本轮检验：在正确分子已经存在于理论候选库时，显式模拟谱差异及真实配对监督，能否提高
实验谱的完整结构检索。完整 canonical SMILES exact match 是首要指标，同时比较
Tanimoto、两版 GED 和有效率；预测过程不调用 LLM API。

**本轮选出的配对模型在最终 200 条测试上 exact match 为 14%（28/200），raw LLM 为
2.5%（5/200）。结构指标均值全部领先，但两版 GED 的配对区间仍跨零，域偏移也没有完全解决。**

## 主要结果

验证阶段保持同一候选池、初始化和评分口径，三组的最佳 checkpoint 如下。

| 方案 | 实验验证 exact match | 验证 Tanimoto | 最佳轮次 | 总训练轮次 |
|---|---:|---:|---:|---:|
| A：理论旧增强 | 1.10%（2/182） | 0.07156 | 6 | 12 |
| B：差异驱动增强 | 1.10%（2/182） | 0.10857 | 11 | 17 |
| C：真实配对适配 | 9.89%（18/182） | 0.28336 | 19 | 25 |

B 提高了结构相似度，但没有增加精确命中数；C 相比 B 的验证 exact 提升 8.79 个百分点，
按分子组重采样的 95% 区间为 4.44–13.59 个百分点。原冻结图模型在同一验证池上的
谱→谱和谱→图均为 2/182，表明只切换原模型的检索路径也没有解决问题。

因此，本轮证据主要支持真实跨域配对监督的作用。C 同时包含域增强，尚不能据此断言
“真实配对监督不需要域增强”；严格分离两者的交互还需要 C 去掉域增强的额外消融。

最终只评分已冻结选出的 C，200 条测试仍使用固定的 10,000 候选。主对照采用严格字段解析：

| 指标 | raw LLM API | 配对模型 C |
|---|---:|---:|
| 有效 SMILES | 99% | 100% |
| 完整 exact match | 2.5%（5/200） | **14%（28/200）** |
| Tanimoto ↑ | 0.194553（198） | **0.265849（200）** |
| legacy GED ↓ | 9.858586（198） | **9.240000（200）** |
| chemical GED ↓ | 6.301075（186） | **5.908163（196）** |

新版 raw kNN 的 exact 为 1/200（0.5%），Tanimoto=0.113178（200），
legacy GED=12.865（200），chemical GED=8.177778（180），有效率 100%。
三种方法共同可计算样本上的顺序也一致：

| 指标 | 共同样本数 | raw kNN | raw LLM | 配对模型 C |
|---|---:|---:|---:|---:|
| Tanimoto ↑ | 198 | 0.113491 | 0.194553 | 0.268208 |
| legacy GED ↓ | 198 | 12.803030 | 9.858586 | 9.161616 |
| chemical GED ↓ | 167 | 8.263473 | 6.311377 | 5.940120 |

括号为可计算样本数，exact 分母始终为 200。相同可计算样本上的配对比较如下；
“改善”统一规定为模型更好时为正，GED 改善为 LLM 减模型。

| 指标 | 配对样本数 | 改善 | 95% bootstrap 区间 |
|---|---:|---:|---:|
| 有效率 | 200 | +1.0 个百分点 | [0, 2.5] 个百分点 |
| exact match | 200 | +11.5 个百分点 | **[6.0, 17.0] 个百分点** |
| Tanimoto | 198 | +0.07365 | **[0.02474, 0.12340]** |
| legacy GED | 198 | +0.69697 | [−0.37374, 1.82336] |
| chemical GED | 183 | +0.42077 | [−0.31694, 1.16393] |

这支持 exact 与 Tanimoto 的提升；对 GED 目前只能报告均值领先，不能声称所有指标都已
统计显著领先。模型使用闭库候选及独立实验训练谱，而 raw LLM 未获得候选列表，两者的
训练资源和输出约束不同，结论限定于本次明确的数据与任务设置。

## 域偏移仍然集中在哪里

事后按最终目标的理论来源拆分，模型在 QME14S 子集为 27/138（19.57%），LLM 为 4/138；
在 fg26 子集两者均为 1/62（1.61%）。整体收益主要来自 QME14S 子集，并不意味着不同
理论来源均已得到充分适配。该拆分只用于解释，未用于选择 checkpoint 或重跑测试。

训练配对也显示来源差异：QME14S 的原始平均谱相关性为 0.54974，峰位拟合后为 0.67857；
fg26 从 0.13156 上升到 0.67405。但 fg26 仅占实验训练配对的 61/568，混合增强与配对训练
没有在其最终测试子集上产生明显 exact 收益。这提示应优先研究按理论来源分开的校正及
均衡采样，而不是直接扩大网络。相关性拟合提升不等于候选检索一定正确。

按实验条件，模型液相为 24/147、固相为 4/51、未注明为 0/2。来源与分子组成并未严格
匹配，不能把这些描述性差异解释成单一因素的因果效应。fg26 测试目标平均重原子数 6.42，
QME14S 为 8.14，因此至少不能简单用“fg26 分子更大”解释这个结果。

下一轮最有针对性的工作是：保留同一结构跨理论来源的多条参考谱、增加来源均衡的真实
配对训练，以及按来源估计校正分布；另加“真实配对但不使用新增域增强”的消融。本轮未
追加这些实验，也未根据已经看到的 200 条测试结果重新选型。

## 数据协议

最终测试使用修复版 `raman_closed_10k_test200_seed0_exact_v2`，候选为 10,000 个唯一完整
结构，测试 200 个分子，目标结构覆盖 200/200。测试身份的理论谱参与训练；实验测试谱
仅在选择冻结后加载。这是已见分子身份、未见实验光谱的闭库迁移，不是未知分子生成。

从现有重合缓存筛出同位素和立体信息一致的理论—实验配对，排除最终 200 个测试组。
剩余 707 个分子组按 seed=0 的 SHA-256 顺序划分，实验训练 530 组/568 条谱、
实验验证 177 组/182 条谱。同组不同实验记录不跨集合，测试组与两者的交集为零。

独立配对结构只有 17 个在固定测试候选库内。为保证验证目标也能被检索，内部验证池
增补 704 个理论参考，形成所有训练方案共用的 10,704 候选池；最终测试只检索原 10,000。
理论训练包括冻结的 9,500 条训练谱和 704 条补充理论谱，共 10,204 条，保留原 500 条
理论内部验证槽位。补充理论参考包含实验验证分子的身份，以对应“身份已见、实验谱未见”
的最终任务；这些分子的实验谱没有参与梯度更新或增强参数拟合。

实验训练配对的理论来源为 QME14S 507 条、fg26 61 条；验证为 157/25 条。
训练实验记录中液相 402、固相 160、未注明 6；验证为 133/42/7。全部实验谱来自 SDBS，
本轮不能支持跨实验数据库或跨仪器的普遍适用性声明。

## 差异估计与模型

先在实验训练配对上做有限网格的全局峰位仿射拟合：频率比例 0.94–1.06、平移
−40 至 +40 cm⁻¹。只有拟合后相关性至少 0.25 且改善至少 0.05 的配对参与频率参数估计。
568 对中 413 对通过该门槛；其 5%–95% 分位范围为比例 0.95–1.014、平移 −25 至 +40 cm⁻¹。
这些参数来自有限搜索，部分达到边界，不代表已确定唯一的物理校正关系。

缩放与平移按整对重采样，保留训练拟合中的相关关系。局部峰位扰动、峰宽、低频基线、
相对峰强变化及噪声参数也由训练配对估计，并设固定数值上限。宽化上限约 12.97 cm⁻¹，
局部位移上限 10 cm⁻¹，平滑相对强度扰动的 log 标准差上限 0.5。覆盖区间从实验训练谱
抽样；当覆盖交集过小，放弃该次新增域扰动，避免生成空谱。

训练配对的相关性均值从 0.50483 上升到拟合后的 0.67809，中位数从 0.54844 到 0.71658。
这是拟合诊断，不能当作独立验证性能；增强是否有效由未参与拟合的实验验证组决定。

三个方案均使用 128 维、3 层、4 头的光谱 Transformer，投影维度 64，patch=16、stride=8。
输入归一化只使用有效覆盖点，注意力屏蔽完全缺失的 patch，池化按有效覆盖比例加权。
原来的图编码器不参与新方法，参考谱编码后绑定完整结构，检索直接返回对应 SMILES。

| 方案 | 训练查询与目标 | 用途 |
|---|---|---|
| A | 理论谱旧增强 → 同一结构理论参考 | 理论训练对照 |
| B | A 加入训练配对估计的域扰动 | 检验显式模拟差异 |
| C | 半批 B、半批真实实验谱 → 同一结构理论参考 | 检验真实跨域配对监督 |

三个方案的初始化权重哈希相同：
`692ae371e79a059f3f1ca30abd160f18e51eb5c2aa1cc105771cd69c5adfff5b`。
统一 AdamW、学习率 0.0003、batch=64、温度 0.1，对称多正样本对比损失；重复身份不互为
负样本。每轮均 160 次更新，C 不因半批理论而增加更新次数。每组最多 20 分钟/60 轮，
验证排序连续 6 轮无改善则早停。epoch 选择依次比较验证 exact、Tanimoto、较低训练损失。

A 的梯度仅使用理论数据，但 checkpoint 也由实验验证集选取，因此不能把 A 描述为完全
不接触实验标注的零样本方案。B 使用训练配对拟合增强，C 进一步直接使用配对标签。

## 评分与解释边界

三个方案均完成后，先写 `final/selection.json`，随后才读取最终实验谱。验证诊断同时比较
raw kNN、覆盖归一化 kNN、旧冻结模型的谱→谱和谱→图路径，以及 A/B/C。旧模型仅用于
诊断，不冒充在修复版数据上训练的新模型。

理论参考谱自查询是索引自检，其 exact 与实验查询 exact 的差距只能描述当前闭库迁移，
不能被解释为未见理论谱上的泛化差距。域差距缩小还必须伴随实验表现上升。

最终仅评测验证选出的模型及新版 raw kNN，复用已有新版 raw LLM 结果，不按测试结果
切换方案。逐条复用原结构评分器，GED 10 秒时限、4 个评分线程；超时保持 null。
报告各自可计算子集、三方法共同子集，以及相对 LLM 的配对差值与 95% bootstrap 区间。
验证差值按分子组重采样，最终 200 条测试每组一条。单个训练 seed 的实验不能衡量训练随机性。
