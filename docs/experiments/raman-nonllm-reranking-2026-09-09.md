# Raman 非 LLM 重排与四组开发验证消融

本轮补充规则覆盖率重排和轻量线性重排器，用于检验候选选择收益是否仅来自规则特征。
所有新实验均在 JJ 完成，没有重训 encoder，也没有新增 LLM API 调用。

**当前结果不支持使用简单规则覆盖率替换检索首位。冻结后的线性“名次＋规则”模型也没有
改变首选候选，因而没有额外收益。** 这补齐了实际运行的非 LLM 对照，但不等于已经证明
LLM 有稳定优势，更不能外推为所有规则库或所有 learned reranker 均无效。

结构，最终测试为原固定的 10,000 个结构，候选身份可参与理论谱训练的闭库设定不变。

训练查询在冻结 encoder 下重新检索 Top10；不把真实结构补入候选，也不使用测试标签

结论。开发验证集先前用于 encoder 选择，Test-200 也已在历次实验中被观察，因此本轮
属于固定基准上的开发与复测，不称为全新的盲测。

## 重排规则与线性模型

统一使用 `scripts/raman_mode_evidence.py` 中的 15 条 Raman 模式记录，与已有
`modes_all_full` LLM 组相同。它们不是全部 181 条旧规则。本轮不扩展频率区间、SMARTS
或来源解释，峰检测复用原 `_PeakDetector`，规则容差固定为 20 cm⁻¹。

对查询命中的每个模式，检查候选是否满足该模式的 SMARTS。规则覆盖率定义为：

\[
 C(q,c)=\frac{\sum_{m\in M(q)}\mathbf{1}[c\text{ 满足模式 }m\text{ 的 SMARTS}]}{\max(1,|M(q)|)}.
\]

这里的分母是查询命中的模式数，不是峰数；每个模式至多计一次。没有证据时记零，
不因缺峰惩罚候选。同分时保留检索顺序。该分数是粗粒度兼容性，不是分子身份概率。

轻量重排器是带 L2 正则的线性模型，包含以下受控版本：

- **名次特征**：仅使用原候选名次的倒数。
- **规则特征**：覆盖率及 15 个“观察峰命中且候选结构兼容”的二值特征。
- **名次＋规则**：合计 17 个特征，为主要 learned reranker。

仅在训练组上计算候选与真值的 Morgan Tanimoto 标签。对每条查询的 45 个候选对，
拟合候选分数差与 Tanimoto 差之间的平方误差；分子组等权，组内谱等权，每谱候选对
等权。特征尺度也仅由训练组等权估计。模型不使用真值分子式、真值指纹或标签作为
推理特征。验证时按组等权 exact、组等权 Tanimoto、较大正则的顺序确定唯一参数。

预设正则网格为 `{0.01, 0.1, 1, 10, 100}`。最终名次模型和名次＋规则模型均选择 100，
规则模型选择 0.01。全部候选参数和验证分数均保留；本轮没有根据测试结果再改参数。

## 同规则的四组开发验证结果

下表全部使用同一 149 条谱、同一 Top10、同一峰检测。LLM 行复用先前成功响应；
“＋规则”指同一套 15 条模式，而不是旧 legacy 规则库。

| 配置 | Exact | 逐谱 exact | 分子组等权 exact | 逐谱 Tanimoto |
|---|---:|---:|---:|---:|
| Retrieval | 16/149 | 10.74% | 10.56% | 0.32815 |
| Retrieval＋Rules，覆盖率 | 10/149 | 6.71% | 7.04% | 0.25852 |
| Retrieval＋LLM | 19/149 | 12.75% | 13.38% | 0.34465 |
| Retrieval＋Rules＋LLM，modes_all_full | 21/149 | 14.09% | 14.08% | 0.33547 |

规则分数直接选择候选和 LLM 接收规则文字属于不同的决策实现；这四组比较的是组件
配置的实际效果，不将两种决策实现视为同一个模型上的纯参数消融。

LLM 加入模式规则后新增 12 条命中、丢失 10 条，逐谱净增 2 条；组等权 exact 增益为
0.70 个百分点，95% 配对分子组 bootstrap 区间为 [−5.63, +6.69] 个百分点。
Tanimoto 的组等权差值为 −0.01051，区间 [−0.06368, +0.04316]。
当前开发验证不能支持规则对 LLM 有稳定增益。单次 LLM 响应的查询重采样也不包含
API 采样重复或模型训练随机性。

额外 learned 对照：名次模型与名次＋规则模型均为 16/149，且所有 149 条首选都与
Retrieval 相同；规则特征单独学习为 15/149、Tanimoto 0.29680。旧 `legacy_kb` 为
22/149、Tanimoto 0.37028，只作为额外参照，未混入上述同规则四组表。

四组在共同可计算查询上的 GED 如下，均为逐谱均值，越低越好：

| 配置 | legacy GED，共同 n=149 | chemical GED v2，共同 n=138 |
|---|---:|---:|
| Retrieval | 8.02013 | 4.57246 |
| Retrieval＋Rules | 9.52349 | 5.30435 |
| Retrieval＋LLM | 7.95973 | 4.53623 |
| Retrieval＋Rules＋LLM | 7.75839 | 4.29710 |

这里 chemical GED 的 138 条共同子集与各方法单独的可计算集合不同。LLM 有/无规则
两组的专属配对集合为 140 条、133 组；按分子组等权，其 chemical GED 改善为 0.26566，
95% 区间 [−0.36591, +0.92732]。legacy GED 的组等权改善为 0.22535，区间
[−0.77113, +1.24657]。两版 GED 同样不足以支持稳定的规则增益。

| 非 LLM 方法 | Exact | Exact rate | Tanimoto | 相对检索首位改选条数 |
|---|---:|---:|---:|---:|
| Retrieval | 41/200 | 20.5% | 0.32053 | 0 |
| 规则覆盖率 | 22/200 | 11.0% | 0.23472 | 145 |
| 线性：仅名次 | 41/200 | 20.5% | 0.32053 | 0 |
| 线性：仅规则 | 23/200 | 11.5% | 0.27090 | 150 |
| 线性：名次＋规则 | 41/200 | 20.5% | 0.32053 | 0 |

以上方法都从合法候选中选择，有效率均为 100%；这不代表它们有生成合法 SMILES 的能力。
覆盖率重排新增 7 条命中、丢失 26 条，exact 差值为 −9.5 个百分点，95% 配对区间
[−15.0, −4.0] 个百分点；Tanimoto 差值为 −0.08581，区间 [−0.13285, −0.03844]。
该简单基线在此固定测试上退化。

名次＋规则模型实际完全保留检索首位，说明本轮模型及特征未获得可用的额外选择信号。
不能因为有监督训练后与检索持平，就宣称学习器已验证有效。这个结果也不能证明更丰富
的候选谱对齐特征、其它规则库或其它模型无法改善结果。

Test-200 已有的“Encoder＋KB＋LLM”使用旧规则，本轮没有新增 15 模式 LLM 测试请求。
因此同规则四组对照目前在开发验证集完整，在 Test-200 尚不能称为严格完整。

非 LLM 方法在共同可计算查询上的结构距离为：

| 方法 | legacy GED，共同 n=200 | chemical GED v2，共同 n=179 |
|---|---:|---:|
| Retrieval | 8.51000 | 5.41341 |
| 规则覆盖率 | 10.56000 | 6.80447 |
| 线性：仅规则 | 9.50000 | 5.87151 |
| 线性：名次＋规则 | 8.51000 | 5.41341 |

“仅名次”逐查询预测与 Retrieval 完全一致，故 GED 也相同。各方法单独可计算的
chemical GED 样本数分别为 193、187、191、193；没有将超时填零。
覆盖率与 Retrieval 的专属配对集合为 183 条，chemical GED 平均增加 1.43169，
95% 区间 [0.83060, 2.04918]，即结构距离进一步变差。该配对集合与表中四方法共同的
179 条集合不同，因此差值不能直接由表中均值相减替代。

## 覆盖率失败的可观察迹象

Test-200 每条查询平均命中 7.385 个模式，没有无规则命中的查询；134/200 条查询有
多个候选取得并列最高覆盖率，其中 3 条所有十个候选同分。此时检索顺序参与打破平局，
因此规则覆盖率不是独立于检索的分类器。大量并列也显示这些粗粒度模式缺少区分能力。

例如 query `3706` 的原首位 `COC(C)(C)CC(C)=O` 就是真值，覆盖率为 0.375；规则重排
选择了原第六名 `CC=C1OC1CC`，覆盖率为 0.5，反而失去 exact。查询 `9443` 的真值
`CC(C)(C)c1ccccc1` 得 0.25，原第七名 `CC1(C)C=CC2COC21` 得 0.5 而被选中。
这些案例说明：在当前宽区间和有限 SMARTS 库下，“能对应更多可能峰归属”不保证结构
更接近真值。覆盖率没有联合振动模式、候选完整理论谱或峰强拟合能力。本轮仅做事后
解释，没有据此修改模式库或重新选择模型，也不将其解释为 Raman 规则本身失效。
